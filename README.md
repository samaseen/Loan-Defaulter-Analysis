# Loan Defaulter Analysis

## Objective  
Analyze bank loan data to derive insights and recommend target customer segments for loan approvals.  

## Dataset  
[Loan Defaulter Data](https://www.kaggle.com/datasets/gauravduttakiit/loan-defaulter/data).  

## Key Steps  
- **Data Cleaning**: Handled missing values, treated outliers, and refined data.  
- **Feature Engineering**: Selected impactful features and created new ones.  
- **Visualization**: Used Matplotlib and Seaborn for insights.  
- **Analysis**: Conducted univariate and bivariate analysis to identify patterns.  

## Insights  
- **Loan Type**: Cash loans have a lower default rate.  
- **Demographics**: Married, highly educated, female, and homeowners are safer segments.  
- **Income**: Customers earning ≤1 million and borrowing ≤1.5 million are less likely to default.  
- **Occupation**: Accountants, managers, core staff, and laborers show lower default rates.  
- **Children**: Safer candidates have 1-4 children.  

## Recommendations  
- Target married, educated females with stable income (≤1 million).  
- Prefer occupations like accountants, managers, and core staff.  
- Focus on loans ≤1 million with annuities ≤50K.  
- Consider customers with previous cancellations, as many repay successfully.  

## Tools  
Python (Pandas, NumPy, Matplotlib, Seaborn), statistical analysis, and feature engineering.  

## Conclusion  
This analysis provides actionable insights to optimize loan approvals and minimize default risks.
